## Brand campaign inquiries

The public inquiry form is available at `/brand-campaign-inquiry`. Apply the database migration with `npx prisma migrate deploy` (then `npx prisma generate` if the client is not regenerated by your install process). Configure these server-only environment variables to enable notifications:

- `RESEND_API_KEY`: API key from your Resend account.
- `CAMPAIGN_NOTIFICATION_EMAIL`: agency inbox that receives submissions.
- `CAMPAIGN_SENDER_EMAIL`: sender address or display-name address verified in Resend.

The API sends a transactional email through Resend, then saves successful submissions in the existing PostgreSQL database. Without all three email settings, it returns an unavailable response and does not report that an email was sent. Keep the API key out of `NEXT_PUBLIC_*` variables.
